# Сеть метеорологических станций регионального центра

Система для сбора наблюдений со станций, авто-проверки данных, учёта приборов
и отчётности региональному центру.

## 1. Сущности

### Станция
id, наименование, тип (наземная, аэрологическая, морская, автоматическая).
ЛК наблюдателя привязывается к станции

### Пользователь
логин, пароль, роль (наблюдатель, руководитель), станция, контакты.

### Параметр
код, название, единица измерения, допустимый диапазон, точность.
Пример: температура, давление, влажность, ветер, осадки, облачность

### Результат проверки
замер, тип проверки (диапазон, соседи, выброс), вердикт (норма, подозрение),
отклонение, значение для сравнения, время, пояснение

### Прибор
id, наименование, станция, измеряемые параметры,
роль (основной, резервный), состояние (в работе, неисправен, на поверке, списан),
дата ввода

## 2. Процессы

### Ввод и передача наблюдений
Наблюдатель вносит форму-замер. Замер уходит в центр.
Нет связи — замеры копятся локально и уходят пакетом при восстановлении канала,
с пометкой «задержанная передача»

### Проверка качества введенных параметров
Выполняет система на бэкенде. Три проверки:
- диапазон: значение против допустимого диапазона параметра;
- соседи: значение против среднего по станциям района за тот же срок;
- выброс: резкое отклонение от собственного ряда станции.

Есть подозрение — замер помечается, как аномалия у руководителя.

### Перепроверка
Наблюдатель видит возвращённые замеры и каждый исправляет и отправляет заново. Исправление  запускает проверку заново

### Приборы и сбои
Наблюдатель отмечает поломку, прибор становится неисправным,
создаётся запись в журнале сбоев у руководителя.
Система следит за сроками поверки, руководитель планирует поверки и график замены

### Отчётность
Руководитель смотрит сводные данные по сети

## 3. Роли и права

### Наблюдатель станции
ЛК наблюдателя = одна станция. Экраны: форма ввода значений, список возвращённых записей и приборы в эксплуатации.

Может:
- вносить и передавать замеры своей станции, повторно отправлять накопленное;
- исправлять значение, пока замер не принят или пока он возвращён;
- отмечать поломку прибора, вести журнал сбоев по своей станции;
- смотреть свои приборы и сроки их поверки.

### Руководитель центра
Станцией не является

Может:
- смотреть замеры всех станций;
- разбирать аномалии: возвращать замер на станцию, закрывать разбор;
- планировать поверки станций/приборов;
- смотреть журнал сбоев по сети.

## 4. Правила и ограничения
### Проверки при вводе
- значение — число с точностью параметра. Вне диапазона принимается, но возможна пометка аномалии;
- прибор должен быть закреплён за станцией.

### Статусы замера
- черновик — внесён, не передан;
- получено — принят центром, ждёт проверки;
- помечено — проверка дала подозрение;
- возвращено — отправлен на станцию;
- перепроверено — наблюдатель подтвердил или исправил;
- принято — прошёл проверку, идёт в отчёты;
- отклонено — недостоверный, в полноту не идёт.

Переходы:
- в «помечено» и «возвращено» переводит система или руководитель;
- в «перепроверено» — только наблюдатель своей станции;
- исправление увеличивает ревизию и запускает проверку заново;
- принятое значение не меняется, только новая ревизия с обоснованием;
- обратные переходы запрещены.


### Целостность
Замеры не удаляются: правки хранятся ревизиями с автором и временем. Смена статуса замера
и состояния прибора пишется в лог-журнал

## 5. Отчётность

Отчёты формирует руководитель. Вывод таблицей, выгрузка в CSV.

### Выбросы и задержанные передачи
Помеченные замеры по станциям и типам проверок, из них подтверждено и исправлено после
перепроверки, доля ложных срабатываний.
По задержкам: количество, суммарная и средняя задержка, время без связи.
Плюс динамика по дням и станции с наибольшим числом аномалий

### Плотность наблюдений по районам
По району: активных станций, площадь, станций на 1000 км², принятых замеров за период,
среднее на станцию. Видно районы с недостаточным покрытием

### Надёжность приборов
Отказы по станциям и моделям, среднее время восстановления, число переходов на резервный,
открытые записи журнала

### Списки региональных представителей
Представитель, район, закреплённые станции, контакты. Районы без представителя выделяются
